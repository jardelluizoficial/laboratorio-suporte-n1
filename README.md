## Comece pelo laboratório

### Active Directory e Windows

Simulação de uma empresa com os setores Financeiro e RH, usando **Windows Server 2022**, **Windows 11** e **Oracle VirtualBox**.

O Active Directory organiza contas e recursos de um domínio Windows. Neste laboratório, pratiquei tarefas de suporte envolvendo login, acesso a arquivos e configurações aplicadas aos usuários.

**[Abrir o laboratório completo →](active-directory/README.md)**
